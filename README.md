# 集集電工業股份有限公司 — 官方網站

以靜態網站方式重構 [集集電工業既有官網](http://www.ccelect.com.tw/chinese/supplier.html)（CCElect），提供公司介紹、產品櫥窗、技術資訊與聯絡管道。


| 項目        | 內容                                                                                                 |
| --------- | -------------------------------------------------------------------------------------------------- |
| 公司        | 集集電工業股份有限公司                                                                                        |
| 參考站       | [http://www.ccelect.com.tw/chinese/supplier.html](http://www.ccelect.com.tw/chinese/supplier.html) |
| 預計框架      | [Astro](https://astro.build/)（靜態輸出 SSG）                                                            |
| 預計主題      | [ProCleaning](https://github.com/anastasiiaxfr/ProCleaning)（Astro + Tailwind + DaisyUI）            |
| 主題選型來源    | [Astro Themes · Free](https://astro.build/themes/2/?search=&price%5B%5D=free)                      |
| 主要語系（參考站） | 繁體中文 / English / 日本語                                                                               |


---

## 專案目標

- 以現代化靜態網站取代既有官網，改善可維護性、載入效能與手機體驗
- 保留既有商務資訊與產品結構精神，視覺與資訊架構可依討論結果調整
- 以 **ProCleaning** 為版型起點，替換成集集電的品牌、文案與產品內容
- 全站以靜態檔案部署，不需常駐應用伺服器

## 本機開發（初始化後）

> 下列指令以 [ProCleaning](https://github.com/anastasiiaxfr/ProCleaning) 的 README 為準；專案實際初始化後若有差異再改此節。

### 環境需求（預計）

- Node.js LTS（建議 20 或以上）
- npm（建議與 theme 一致）

### 指令

```bash
cd ccelect
npm install
npm run dev      # 本機開發，預設 localhost:4321
npm run build    # 產出於 ./dist/
npm run preview  # 預覽建置結果
```

建置產物目錄通常為 `dist/`，可整包上傳至靜態主機。
