# 集集電品牌色票

網站與印刷／數位素材共用的主色定義。實作時建議對應 CSS 變數（見下方）。

## 色票

| 用途       | 色彩     | 色碼      |
| ---------- | -------- | --------- |
| 企業主色   | 電力藍   | `#265CA6` |
| 深色主色   | 深靛藍   | `#2B3A95` |
| 亮色主色   | 科技藍   | `#2596D1` |
| 深藍背景   | 工業深藍 | `#193773` |
| 行動強調色 | 閃電黃   | `#FCF002` |
| 接地輔助色 | 接地綠   | `#A6CC36` |
| 頁面背景   | 淺藍灰   | `#F4F7FB` |
| 主要文字   | 深灰藍   | `#172234` |
| 次要文字   | 中性灰   | `#5E6878` |
| 邊框       | 淺灰藍   | `#D9E2EE` |

## 使用原則（建議）

| 角色              | 色碼                  | 典型用途                                           |
| ----------------- | --------------------- | -------------------------------------------------- |
| 主品牌            | `#265CA6`             | Logo 搭配、導覽 active、標題強調、主按鈕           |
| 深層 / Header     | `#2B3A95`、`#193773`  | 頁首、頁尾、深色區塊背景                           |
| 亮點 / 連結 hover | `#2596D1`             | 次要按鈕、連結、圖示高亮                           |
| CTA               | `#FCF002`             | 諮詢、LINE、立即聯絡等行動按鈕（配深色字）         |
| 輔助              | `#A6CC36`             | 接地／永續／成功狀態、圖示點綴（勿大面積取代主藍） |
| 頁面底            | `#F4F7FB`             | 全站背景；卡片可用白 `#FFFFFF`                     |
| 文字              | `#172234` / `#5E6878` | 標題與正文 / 說明、caption                         |
| 線條              | `#D9E2EE`             | 分隔線、輸入框、表格邊框                           |

**對比注意：** 閃電黃 `#FCF002` 上的文字請用深色（建議 `#172234`），勿用白字。深色背景上的主按鈕可用白字 + 電力藍／科技藍。

## 實作位置（Jetstream）

| 檔案                               | 內容                          |
| ---------------------------------- | ----------------------------- |
| `src/styles/variables/_colors.css` | 色階 + `--palette-*` 色票別名 |
| `src/styles/themes/_light.css`     | 亮色語意 token（主用）        |
| `src/styles/themes/_dark.css`      | 暗色語意 token                |

語意層常用：`--color-brand`、`--color-accent`、`--color-earth`、`--color-bg`、`--color-text`、`--color-border`。  
色票層：`--palette-brand` 等與上表色碼一一對應。
