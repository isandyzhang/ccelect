# 字體

| 角色                     | 字體                                                       |
| ------------------------ | ---------------------------------------------------------- |
| 主字體（中文／UI／標題） | **思源黑體**（網頁：`Noto Sans TC`，Astro 自架 400／700） |
| 等寬（型號／code）       | JetBrains Mono（用到時載入，不 preload）                   |

設定入口：[`site-fonts.mjs`](../site-fonts.mjs)。CSS 變數見 [`src/styles/variables/_fonts.css`](../src/styles/variables/_fonts.css)。
